# SP Tech Solutions

A professional Django-based Digital Service Agency Website.

## Features

- Dynamic Services
- Dynamic Portfolio
- Testimonials
- FAQ
- Contact Form
- File Upload
- Email Notifications
- Admin Dashboard
- Order Management
- Responsive Design

## Tech Stack

- Python
- Django
- Bootstrap 5
- HTML5
- CSS3
- SQLite
- Git & GitHub

## Installation

```bash
git clone https://github.com/Shivutech/SP-Tech-Solutions.git

cd SP-Tech-Solutions

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
